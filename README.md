# 自行车车架材料对比表（HTML 勘误版）

50+ 种车架材料的单页对比表，纯静态 HTML。

在线访问：https://richelsky.github.io/bike-materials/

- `index.html` 页面本体，数据与样式全部内联，零外部依赖

内容涵盖：铝合金（6 系/7 系/钪合金）、钢材（Reynolds/Columbus/Kaisei 等管商）、
钛合金（Gr1-Gr12、β 钛）、碳纤维（Toray/Hexcel/品牌技术）、镁合金、
生物基与 3D 打印等新兴材料，以及比强度/比刚性/舒适性/耐用性等综合对比。
2026-10-13 勘误 20 处（材料类型、牌号、品牌技术归属、比强度比刚性排序重算），
页面内黄色高亮标注，悬停可见原值。

数据整理自公开技术资料与制造商规格书；标"约"处为厂方未公开精确值的估算。
