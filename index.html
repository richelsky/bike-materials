5镁合金系列

比铝还轻三分之一的材料，但整车架基本绝迹——腐蚀和疲劳两道坎迈不过去，现在只活在零部件里。

材料牌号状态抗拉强度 (MPa)密度 (g/cm³)特点与应用

AZ61AF310-3401.80高强度镁合金
AZ80AT5380-4201.81超高强镁合金
ZK60AT5340-3801.83高强镁合金，极少用于自行车
WE43T6250-2801.84高温镁合金，耐腐蚀较好
Elektron 21 (EV31A)T6280-3201.80稀土镁合金，高性能

优点

  • 密度最低（1.77），比铝轻约 1/3
  • 减震性好
  • 机加工性能好

缺点

  • 耐腐蚀性差（需特殊表面处理）
  • 焊接困难（易燃）
  • 疲劳性能较差
  • 成本高

实际应用

  • 1990 年代曾有镁合金整车架尝试（如 Merida 镁合金概念车），未成主流
  • 目前主要用于零部件：座管、把立、曲柄
  • 3D 打印镁合金仍在研发阶段

舒适性（路感，主观从高到低）

  1. 钢（531 / 853 / Columbus Spirit）——弹性形变范围大，路感公认最佳
  2. 钛合金（Gr9）——类似钢的质感，且不怕锈
  3. 生物基复合材料（亚麻/竹）——天然减震
  4. 碳纤维——取决于铺层设计，可调教空间大
  5. 铝合金——路感偏硬，需靠管型设计补偿
  6. 镁合金——减震性好但应用太少，无从比较

耐用性（从高到低）

  1. 钛合金（Gr2/Gr9）——几乎不腐蚀，寿命数十年
  2. 不锈钢钢架（725/931/953）——耐腐蚀，寿命长
  3. 碳纤维——不腐蚀，但存在疲劳与冲击损伤风险（紫外线/磕碰）
  4. 钢（需涂装保护）——会锈，需维护，但可修
  5. 铝合金——会腐蚀，焊缝/应力集中处是薄弱点
  6. 镁合金——耐腐蚀差，需特殊保护

可修复性（从高到低）

  1. 钢——可焊接、可矫直、可重喷，路边店都能救
  2. 钛合金——可 TIG 焊，但会焊的师傅不多
  3. 铝合金（6061 等 6 系）——可焊但热处理状态被破坏，强度打折
  4. 7 系铝 / 高模碳纤——基本无法满意修复
  5. 碳纤维——结构性损伤只能更换
  6. 镁合金——几乎不可修复

成本（从高到低）

  1. 超高模量碳纤 / Reynolds 953 / 3D 打印钛定制
  2. 高模量碳纤（T1000/M40J）/ 钪合金铝 / Reynolds 853 / 钛架
  3. 中模量碳纤 / 高端铝（7075）/ Columbus XCR
  4. 标准模量碳纤 / Reynolds 520-753 / 生物基材料
  5. 6061/6069 铝合金 / 普通钢 / 镁合金零部件

环境影响（从环保到不环保）

  1. 生物基复合材料——可再生、可降解
  2. 钢——100% 可回收，能耗中等
  3. 铝——100% 可回收，但原生铝能耗极高（再生铝省 95% 能耗）
  4. 钛——可回收，但冶炼能耗高
  5. 碳纤维——热固性树脂难回收，焚烧/填埋为主
  6. 镁——回收有燃爆风险

8选择建议

公路竞赛 / 计时赛：超高模量碳纤（T1000/M40J 级，FACT 12 同级）；预算有限就 7075/钪铝（Cannondale CAAD 一路）。要的就是轻 + 硬。
长途旅行：钢（Reynolds 853 / Columbus Spirit）或钛（Gr9）。路感、耐用、可修、能带货架，坏在路上也救得回来。
山地车：铝（6069-T6 液压成型）是当前性价比之王；高模碳纤做 Enduro/XC 竞赛级；钢架玩 Trail 也很有意思。
通勤 / 训练：6061-T6 铝 / 标准模量碳纤 / Reynolds 525 钢。别为用不上的性能花钱。
定制 / 收藏：钛（Gr9/Gr5）、Reynolds 953、生物基材料。买的是独一无二，不是参数。
环保优先：再生钢 / 再生铝 / 竹、亚麻车架；避开难回收的热固性碳纤。
预算有限：6061-T6 铝架 + 好轮组，二手老款标准模量碳纤也很香。

单位与口径说明

比强度
抗拉强度 ÷ 密度。1 MPa·cm³/g = 1 kN·m/kg，故 7000÷1.79 ≈ 3910 kN·m/kg = 3.91 MN·m/kg
比刚性
弹性模量 ÷ 密度，同一换算口径
MPa / GPa
1 GPa = 1000 MPa
T6 / T1
T6 = 固溶热处理 + 人工时效；T1 = 自然时效
